# CV Project Ideas

Every Sunday, the `haftalik-proje-onerisi.yml` workflow looks at the past
week's topics in `DAILY-TOPICS.md`, generates small project ideas that could
be added to a CV, and appends them here (newest suggestion on top). You
don't need to edit this file by hand, but you can add a note/status next to
an idea you like (e.g. "started", "completed", "not interested").
