# Daily Topic Log

class. The more detail you write, the more accurate the evening
reinforcement quiz (`ders-pekistirme.yml`) and weekly project suggestion
(`haftalik-proje-onerisi.yml`) will be. Example format:

```

- Thermodynamics: Entropy and the second law, Carnot cycle examples
- Fluid Mechanics: Bernoulli's equation, continuity equation
```

Add the new day at the top (newest entry on top), don't delete old ones —
the weekly project suggestion agent may also look at past days.
