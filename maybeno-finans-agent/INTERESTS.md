# Interest Areas

This file determines which topics the **Finance Agent** looks at during its
weekly scan. The agent reads this list, searches for current
opportunities/news for each interest area, and sends a report to Telegram.

To add a new interest area, add a line/item below in the same format.
Instead of deleting one, marking it as "Inactive" preserves the history.

## Active Interest Areas

- **Scholarships and competitions in software/AI** — university scholarships,
  hackathons, AI/ML competitions, coding competition prizes (especially ones
  open to students).
- **Student-oriented investment opportunities/funds** — student-friendly
  investment vehicles, low-entry-barrier funds, general market/fund news
  (not personalized advice, for general information purposes).
- **Chemical engineering + finance intersection opportunities** — finance/
  analysis/risk positions aimed at people with a chemical engineering
  background, related internship programs, scholarship/competition
  opportunities that combine these two fields.
- **General internship/job opportunities (finance & technology)** — newly
  opened internship programs, "new graduate" positions, listings with
  approaching application deadlines.

## Inactive / Paused Interest Areas

(none right now — move an interest area here if you want to pause it)

## Note

When adding a new interest area, be as concrete as possible (e.g. instead of
"general finance," use "student-oriented investment funds"), so the agent
finds more accurate results.
