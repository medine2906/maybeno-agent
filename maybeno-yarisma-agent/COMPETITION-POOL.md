# Competition / Hackathon Pool

This file is the central list of all tracked competitions and hackathons.
When you find a new competition announcement (or someone tells you about one), add a
new row to the table below with the status **"Evaluating"** (edit by hand or open a PR).

The `degerlendirme.yml` workflow runs every day, finds rows with status "Evaluating",
does research, and updates the status (Good Fit / Not a Fit). Later, once you've applied,
you can manually update the status to "Applied", and once the result is announced, to
"Resolved".

## Status values

- `Evaluating` — not yet reviewed by the agent, waiting in the queue
- `Good Fit` — reviewed by the agent, found to match the profile
- `Not a Fit` — reviewed by the agent, does not match the profile or is not recommended
- `Applied` — application submitted, result pending
- `Resolved` — result announced (won / didn't win, add notes)
