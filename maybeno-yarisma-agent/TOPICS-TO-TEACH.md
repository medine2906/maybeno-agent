# Topics to Teach

This file is the list of "topics you need to learn to prepare for this competition"
that the `degerlendirme.yml` workflow identifies while evaluating a competition.

Purpose: This list is meant to be read by a separate repo, **`maybeno-yazilim-ogretmen`**,
and turned into a lesson/curriculum plan based on the topics here. This repo does not
teach lessons itself — it only produces the "these should be taught" list.

Each time a new topic is added, a short note is included about which competition it came
from and why it's needed.
